# Local data access
Obtain the original RecoGCN dataset via https://github.com/fenglixu/RecoGCN (Dataset section). Cite Xu et al., DOI 10.1145/3357384.3357924. No third-party data are included.
For an H5 file containing root datasets train_sample, test_sample and val_sample (N x 3, user, selling agent, item), install core/requirements.txt and run `python data_access/extract_h5.py /path/to/data.h5 /path/to/local_csv`. If the upstream layout differs, inspect it locally before adapting the extraction. The H5 adapter was tested with a locally constructed H5 from archived split CSVs, not a fresh upstream H5 download.
Alternatively supply headered CSVs named train_sample.csv, test_sample.csv, val_sample.csv, with user_id, agent_id, item_id columns. For headerless three-column CSVs add those headers without dropping the first record. Preserve duplicates and integer identifiers. The pipeline concatenates train, test, val and checks counts and unique IDs. Run `python run.py /path/to/local_csv` from the archive root. Generated data remain local.
